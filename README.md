# SQL Data Analysis Project

## Project Overview
This project demonstrates SQL-based data analysis using a sample sales database.

- MySQL
- SQL

- GROUP BY
- HAVING
- JOIN
- Subqueries
- CTE
- Window Functions
- CASE statements

- Best-selling products
- Monthly sales analysis
- Second-highest salary
- Customer-wise spending
- Ranking using window functions
